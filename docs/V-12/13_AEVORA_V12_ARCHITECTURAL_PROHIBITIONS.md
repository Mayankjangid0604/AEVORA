# AEVORA V12 — Architectural Prohibitions

V12 must never:
1. create a company independently of Aevora;
2. create fake employees or leadership identities;
3. create second enterprise authorities;
4. create second employee/company/task/project databases;
5. create second intelligence/improvement/orchestration systems;
6. grant authorization from physical presence;
7. invent activity merely to make the world look alive;
8. spawn decorative pedestrians or fake traffic as enterprise activity;
9. treat visual simulation as business truth;
10. silently mutate state after an unauthorized action;
11. use VR input to bypass authorization;
12. require a keyboard for core VR operation;
13. prematurely lock the 3D engine;
14. require literal Earth geography;
15. freeze the world when the Chairman changes location.

When uncertain, prefer authoritative truth plus explicit stale/unavailable state over invented visual activity.
