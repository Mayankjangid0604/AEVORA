# AEVORA V12 — Implementation Roadmap

## Phase 0 — Documentation
Lock architecture, decisions, boundaries, contracts, security and acceptance criteria.

## Phase 1 — Initial audit
Audit V1–V11. Produce `AEVORA_V12_INITIAL_AUDIT.md`. STOP for approval.

## Phase 2 — World-State foundation
Build gateway, identity mapping, company/building/person projections, event consumption and spatial contracts.

## Phase 3 — 2D control world
Company map, buildings, employees, departments, overlays and realtime updates.

## Phase 4 — 2.5D
Building interiors, navigation, digital-human foundation, vehicles and workplace objects.

## Phase 5 — 3D proof-of-concept
Evaluate engines using the formal POC criteria. Do not prematurely lock the engine.

## Phase 6 — 3D enterprise world
Persistent geography, buildings, campuses, humans, vehicles, environment, audio and executive interaction.

## Phase 7 — VR
Headset, controllers, voice, hand interaction, comfort and executive interface.

## Phase 8 — Advanced embodiment
Autonomous workdays, meetings, travel, richer digital humans, company evolution and history/replay.

## Phase 9 — Final acceptance
Enterprise truth, security, resilience, performance, VR and V1–V11 regression.

## Rule
Never skip the audit gate and never build a parallel enterprise system.
