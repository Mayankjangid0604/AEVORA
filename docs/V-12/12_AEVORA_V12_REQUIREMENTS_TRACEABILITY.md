# AEVORA V12 — Requirements Traceability

Every requirement must map to:

Requirement → Architecture decision → Owning subsystem → Source of truth → Event/contract → Implementation → Test → Acceptance evidence.

## Mandatory invariants
- Dynamic entities have authoritative Aevora sources.
- Physical presence never equals authorization.
- V8 company isolation remains intact.
- V12 creates no parallel enterprise authority.
- The world persists while the Chairman is elsewhere.
- Meaningful enterprise changes propagate in realtime.
- Enterprise truth wins over visualization/simulation.
- VR controllers + voice do not require a keyboard.
- Architecture supports 2D → 2.5D → 3D → VR and future AR/MR.
