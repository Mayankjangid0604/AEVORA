# AEVORA V12 — VR & Interaction Specification

## Views
- Chairman first-person
- third-person
- executive overhead/map
- authorized entity follow/inspection
- vehicle interior/exterior/chase
- immersive VR
- future AR/MR using the same world state

## VR is first-class
VR supports headset, hand controllers, gaze, pointing, spatial selection, grabbing, wrist/hand executive UI, enterprise map, contextual information, buildings, vehicles and voice.

## No keyboard requirement
Core VR operation must not require a keyboard.

## Action-based input
Inputs map to semantic actions such as Move, Turn, Select, Interact, Grab, Navigate, Call, Inspect, Confirm and Cancel. Hardware-specific buttons are not hardcoded into enterprise behavior.

## Multimodal commands
Voice + gaze + pointing + current location + selected entity + company/room/meeting context combine to resolve intent.

Example: point at Research and say “Take me there.”

## VR comfort
Support seated/standing modes, adjustable movement, snap/smooth turning, comfort transitions, destination-based movement and voice-directed travel.
