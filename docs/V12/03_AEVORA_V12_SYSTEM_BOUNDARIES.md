# AEVORA V12 — System Boundaries

## Non-negotiable rule
V12 is a visualization/control layer over V1–V11, not a second enterprise.

## Aevora owns
- company and employee truth
- leadership identities
- departments/teams
- tasks/projects/meetings as business state
- intelligence/improvement/orchestration/autonomy
- authorization
- business events
- enterprise decisions

## V12 owns
- spatial representation
- coordinates/transforms
- visual assets and identity mapping
- navigation representation
- simulation/physical embodiment
- rendering
- spatial interaction
- spatial continuity/history

## V12 must not create
- second company database
- second employee database
- second CEO/Chairman/Assistant authority
- second task/project system
- second intelligence system
- second improvement system
- second orchestration/autonomy system
- second authorization authority

## Truth invariant
If business state, world state, simulation state and rendering state disagree, authoritative Aevora business state wins and lower layers reconcile.
